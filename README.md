# CABIN-CHAT

This application serves as my first foray into the world of Go. The plan is to build a mini-Discord/IRC/WhatsApp type platform that will be locally hosted on my home lab, allowing for me and my close friends to log in with working auth and chat to each other, react, and send photos.

The home lab runs Ubuntu, which means the application will be developed using Linux, although most development work will happen on my Windows laptop machine.

GPT 5.4 (for now) will be used for planning and researching the project, but all code will be written and tested by me (@wjbetech).
